# 数据与模型契约

先看字段单位和历史截止，再解释预测与排班。

## 现场观测

| 字段 | 含义 | 单位 | 样本常见范围 |
| --- | --- | --- | --- |
| `slack` | 距截关 | 分钟 | 15–102 |
| `distance` | 转送距离 | 百米 | 2–42 |
| `bags` | 同批转运行李 | 件 | 1–24 |
| `belt` | 皮带占用 | % | 14–98 |
| `priority` | 短接标签比例 | % | 0–100 |
| `transfer` | 已用中转 | 分钟 | 0–54 |

## 可见性与结果

`day` 为业务序列日，`received` 是录入日期。`revision` 只在可见窗内选最大版，同版内容冲突整键隔离。`arrival` 和 `window` 用当日分钟表示，分派沿半开区间，片区和 `pool` 标识不同业务位置。

历史结果字段 `target` 表示转运未赶上，`outcome_day` 是结果首次可见日。`complete=0` 的不完整单据不参与普通标签回放，清线模型按右截尾留作下界。结算项目的 `target` 是参考发电量，`confirmed` 表示实测表计偏差是否被稽核确认。

## 正则化逻辑回归

用时间裕度、传送带占用和交互项建立逻辑回归，牛顿迭代带 L2 正则和限步。剩余时间权重保持非正，片区修正按有效样本数收缩。

风险分数可能是概率、校准概率或历史异常百分位，取决于回放的 `adjustment`。

特征中位和尺度只在训练窗估计。无已知片区、缺关键测量或超出训练支撑会转人工。归因记录单轴回到训练参考值后对原始分数的变化。

## 资源和发布

一单位资源为优先运力车位。必须保留分拣交接，车位优先留给截关提前量最小的合规行李。
预算等于已用、可用剩余、预留三者之和。发布复核固定模型和源摘要，同时检查当前版本。已发布内容通过不可变标识回看。
